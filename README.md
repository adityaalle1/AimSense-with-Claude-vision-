# AimSense-with-Claude-vision-
(You need an anthropic API key, and results are not accurate) AimSense AI is a browser-based FPS aim analyzer powered by Claude Vision. Upload clips from games like VALORANT, CS2, Apex, Overwatch, R6, Warzone, or Fortnite to get rank estimates, performance scores, coaching tips, recommended drills, radar charts, and frame-by-frame feedback.
